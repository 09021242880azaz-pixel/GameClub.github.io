# GAME CLUB — راه‌اندازی و استقرار

سایت به‌صورت فایل‌های استاتیک (HTML/CSS/JS) است و روی **GitHub Pages** اجرا می‌شود.
داده‌ها، ورود مدیر و فایل‌ها در **Supabase** نگهداری می‌شوند و هوش مصنوعی از طریق **Edge Function** اجرا می‌شود.

## ساختار فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | صفحه اصلی |
| `games.html` | کتابخانه، جستجو، فیلتر و مرتب‌سازی |
| `game.html` | جزئیات بازی، گالری، ویدیو و نیازمندی‌ها |
| `ai.html` | دستیار هوشمند (پیشنهاد بازی و تحلیل سازگاری) |
| `admin.html` | پنل مدیریت (فقط مدیران) |
| `styles.css`, `pages.css` | طراحی (شیشه‌ای، طلایی/نارنجی، RTL) |
| `i18n.js`, `i18n-extra.js` | ۱۸ زبان؛ پیش‌فرض فارسی |
| `app.js`, `pages.js`, `ai.js`, `admin.js` | منطق صفحات |
| `config.js` | آدرس و کلید عمومی Supabase |
| `schema.sql` | جداول، امنیت (RLS)، فضای ذخیره‌سازی و نمونه بازی |
| `ai-assistant.ts` | Edge Function هوش مصنوعی |

## ۱. ساخت پروژه Supabase

1. در [supabase.com](https://supabase.com) یک پروژه بسازید.
2. از **SQL Editor** محتوای `schema.sql` را اجرا کنید (یک بار).

## ۲. ساخت حساب مدیر

1. **Authentication → Users → Add user** را بزنید و ایمیل و رمز عبور مدیر را بسازید.
2. در **SQL Editor** اجرا کنید:

```sql
insert into public.admin_users (user_id)
select id from auth.users where email = 'you@example.com';
```

3. (توصیه می‌شود) **Authentication → Providers → Email** را بروید و گزینه «Allow new users to sign up» را خاموش کنید تا کسی بتواند خودش ثبت‌نام کند.

## ۳. تنظیم `config.js`

از **Project Settings → API** مقدار `Project URL` و `anon public` را در `config.js` قرار دهید.
**هرگز** کلید `service_role` را در فایل‌های سایت نگذارید.

## ۴. Edge Function هوش مصنوعی

1. فایل `ai-assistant.ts` را در مسیر `supabase/functions/ai-assistant/index.ts` قرار دهید.
2. Supabase CLI را نصب کنید و وارد شوید:

```bash
supabase login
supabase link --project-ref <YOUR-PROJECT-REF>
supabase secrets set ANTHROPIC_API_KEY=<your-anthropic-key>
supabase functions deploy ai-assistant
```

3. در `ai-assistant` مقدار `Access-Control-Allow-Origin` را به آدرس GitHub Pages خود محدود کنید.

## ۵. انتشار روی GitHub Pages

1. یک مخزن بسازید و همه فایل‌های سایت را در ریشه آن قرار دهید.
2. **Settings → Pages** را باز کنید، `Deploy from a branch` و شاخه `main` با پوشه `/ (root)` را انتخاب کنید.
3. آدرس نمایش داده‌شده را در **Supabase → Authentication → URL Configuration** به‌عنوان Site URL ثبت کنید.

## ۶. استفاده از پنل مدیریت

- به `admin.html` بروید و با حساب مدیر وارد شوید.
- **لوگو:** در بخش «لوگوی سایت» فایل را آپلود کنید؛ لوگو بلافاصله در همه صفحات نمایش داده می‌شود. تا زمانی که لوگو آپلود نشود، جای آن خالی است.
- **بازی‌ها:** افزودن، ویرایش، حذف، کاور، گالری، ویدیو، لینک فروشگاه و دانلود، نیازمندی‌ها، ویژه و محبوب.
- **پلتفرم‌های دیگر:** اینستاگرام، یوتیوب، روبیکا، تلگرام و لینک‌های سفارشی.

## نکات مهم

- **زبان‌ها:** رابط کاربری در ۱۸ زبان است و پیش‌فرض فارسی است. عنوان، توضیحات و سایر محتوای بازی‌ها همان‌طور که وارد می‌شوند نمایش داده می‌شوند و به‌صورت خودکار ترجمه نمی‌شوند.
- **پاسخ‌های هوش مصنوعی** به زبان انتخاب‌شده کاربر نوشته می‌شوند.
- **سازگاری سیستم:** RAM و فضای ذخیره‌سازی با قاعده مشخص سنجیده می‌شوند. هوش مصنوعی فقط پردازنده و کارت گرافیک را ارزیابی و توضیح می‌دهد و هرگز FPS تضمین‌شده نمی‌دهد.
- **بازی‌های نمونه** در `schema.sql` خیالی هستند؛ آن‌ها را از پنل مدیریت ویرایش یا حذف کنید.
- **هزینه:** هر درخواست هوش مصنوعی هزینه API دارد. برای محدودسازی نرخ، می‌توانید در Edge Function یا از طریق Supabase محدودیت اضافه کنید.
- **ویدیو:** برای فیلم‌های بزرگ لینک یوتیوب بهتر است؛ فایل‌های آپلودشده فضای پروژه Supabase را مصرف می‌کنند. با حذف بازی، فایل‌های آپلودشده آن حذف نمی‌شوند.
- **پیش‌نمایش ویدیو هنگام hover** در این نسخه پیاده‌سازی نشده است.
